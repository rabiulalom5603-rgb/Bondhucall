বন্ধু কল — Android Studio প্রজেক্ট
================================

এটি একটি প্রাথমিক Android Studio প্রজেক্ট; APK ফাইল নয়।

APK বানানোর জন্য:
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. এই ZIP ফাইল Extract করুন।
3. Android Studio থেকে Open নির্বাচন করে BondhuCall ফোল্ডার খুলুন।
4. Gradle Sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
5. Build > Build APK(s) নির্বাচন করুন।

অ্যাপ চালানোর জন্য:
1. Daily.co-তে অ্যাকাউন্ট খুলে একটি room তৈরি করুন।
2. অ্যাপ খুলে সেই রুমের URL দিন, যেমন https://your-room.daily.co/roomname
3. ক্যামেরা ও মাইক্রোফোনের অনুমতি দিন।
4. অন্য ব্যবহারকারীকে একই রুম URL দিন।

সীমাবদ্ধতা:
- এই ZIP-এ কম্পাইল করা APK নেই; APK বানাতে Android Studio/Gradle build দরকার।
- বাস্তব কল Daily.co রুম/পরিষেবা ও ইন্টারনেটের ওপর নির্ভর করে।
- এটি প্রাথমিক নমুনা, Play Store প্রকাশনার জন্য প্রস্তুত পণ্য নয়।
- ব্যবহারকারীদের ব্যক্তিগত তথ্য বা নিরাপত্তার জন্য প্রকাশের আগে পরীক্ষা ও গোপনীয়তা নীতি যোগ করুন।
